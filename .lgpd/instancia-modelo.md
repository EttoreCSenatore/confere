# Ficha da instância (modelo)

Quem hospeda uma instância do Confere é o **controlador** dela (LGPD, art. 5º, VI). Antes de anunciar uma instância pública, copie este arquivo para `instancia.md` (fora do Git, se tiver dados pessoais) e preencha. A política de privacidade (`policies/privacy-policy-v1.md`) usa estes campos.

| Natureza (pessoa física, associação sem fins lucrativos, empresa) | |
| Atividade econômica organizada? (define o art. 15 do Marco Civil) | sim / não |
