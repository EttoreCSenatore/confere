# Changelog / Histórico de mudanças

## 0.1.0 — 2026-11-17

**EN** — First public release.
- API: CNPJ check with explainable signs, "safe to pay?" (CNPJ + bank + Pix), open-data explorer with CSV, weekly local copy of the public lists (works without BrasilAPI for those).
- Web app (pt-BR/English, dark theme, mobile), CLI (`confere-cli`), Docker/Caddy deployment, security CI, bilingual docs.
- Privacy by design (LGPD): no accounts, no history, no IP or identifiers in logs. AI-assisted compliance review; **not legal advice**.

**PT-BR** — Primeira versão pública.
- API: checagem de CNPJ com sinais explicados, "pode pagar?" (CNPJ + banco + Pix), explorador de dados abertos com CSV, cópia local semanal das listas públicas (funciona sem a BrasilAPI para elas).
- App web (pt-BR/inglês, tema escuro, celular), CLI (`confere-cli`), implantação com Docker/Caddy, CI de segurança, documentação bilíngue.
- Privacidade por padrão (LGPD): sem conta, sem histórico, sem IP nem identificadores em log. Revisão de conformidade assistida por IA; **não é aconselhamento jurídico**.
