# Licença

O Confere é **software livre e de código aberto**.

| Parte | Licença |

| Código (API, web, CLI, scripts) | [GNU AGPL-3.0-or-later](https://www.gnu.org/licenses/agpl-3.0.html) (arquivo `LICENSE`) |
| Documentação e imagens de demonstração | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.pt-br) (arquivo `LICENSE-DOCS.md`) |

## Por que AGPL

Como o Confere é um serviço de rede, a AGPL garante que quem o hospedar com modificações também compartilhe o código dessas modificações com os usuários. Usar, estudar, modificar e redistribuir é livre.

## Dados de terceiros

Os dados consultados vêm da [BrasilAPI](https://brasilapi.com.br/) e das fontes públicas que ela agrega (Receita Federal, Banco Central, IBGE, CVM e outras). Eles não são cobertos por esta licença e seguem os termos de cada fonte.
